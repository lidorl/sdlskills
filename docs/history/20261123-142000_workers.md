## Discoveries
- **Meta-repo deliverables are dropped (Important).** The worker publishes only an effort's own docs (feat-req, design, plans, history). Two real runs lost work. A trivial effort's deliverable `docs/notes/hello.md` was salvaged while the effort reported `IMPLEMENTED`. A design run's ADR `docs/decisions/001_release-baseline.md` was salvaged too. The design skill's companion docs (`docs/decisions/`, `docs/design/architecture.md`, `docs/design/data-model.md`) and any deliverable living in the meta repo never reach the board.
- **Trivial tier doesn't fit the loop.** `classify-change` sent a docs-only effort down the trivial path: implemented directly, no plan. The worker's plan-based "development done" check logged a warning, and the effort still reported `IMPLEMENTED`.
- **Installer:** installing into `.` names the adopter's package `"."`.
- **Cost:** a design-phase run on `claude-sonnet-5-5` cost about $0.19 with cached context. Each phase run took 30–45 s.

## Decisions
- The Copilot worker smoke run is deferred to `docs/kit-open-items.md`.
- The two Important discoveries go to Plan 3's final review fix wave, not a new task.
